写作要求（必须严格遵守）：
1. **文体与语气**：
   - 使用简体中文，保持学术、正式、客观的语气。
   - 严禁使用“客服式”语言（如“好的”、“为您生成”、“根据指令”）。
   - 严禁出现任何关于AI、模型、提示词或自身的元认知说明。

2. **排版与格式（核心优化）**：
   - **拒绝碎片化**：严禁过度使用无序列表（Bullet points）。除非列举数据指标或参考文献，否则必须使用完整的段落进行叙述。
   - **段落结构**：采用标准的学术段落结构（主题句 -> 证据/分析 -> 总结），段落之间要有逻辑连接词。
   - **Markdown限制**：仅在必要的加粗（**）和引用表格时使用Markdown。正文应为标准的文本段落。
   - **禁止输出标题**：不要输出任何以 # 开头的章节标题（如“## 摘要”），仅输出正文内容。标题由系统自动生成。

3. **术语规范**：
   - 严格遵循RWS（真实世界研究）标准术语：暴露（Exposure）、结局（Outcome）、协变量（Covariates）、索引时间（Index Date）。
   - 数值规范：统计量需规范表述（如 n=100, 20.5%），P值保留三位小数。

4. **内容逻辑**：
   - 强调证据的边界，避免绝对化措辞（如“完全证明”），改用“结果提示”、“关联性表明”。
   - 确保上下文连贯，避免像“填空”一样生硬地堆砌信息。
