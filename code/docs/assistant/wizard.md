# 新建研究向导

- 步骤：填写主题 → 上传Excel → 生成研究计划 → 生成并执行代码
- 计划生成支持流式预览；可中断、重试、编辑并保存
- 研究计划预览支持结构化“步骤”展示与原始JSON折叠查看
- 执行阶段实时展示日志与代码片段，生成图表与报告草稿

建议：
- 在Excel描述中补充字段含义、sheet结构与关键变量
- 生成后优先检查计划的可执行性与字段映射
- 如日志出现字段不存在，回到计划编辑修正并保存

操作要点：
- Excel结构预览：以树形折叠展示 `excel_info`（默认折叠）
- 研究计划预览：顶部显示 `objective`；分卡片展示 `steps` 的标题、方法、输入输出等要点；原始JSON可折叠查看
- 代码查看器：深色背景、行号与简易语法高亮；超长代码自动折叠前若干行
- 流式生成：计划与章节生成过程中可使用“中断”按钮停止当前流
- 保存计划：在编辑框修改后点击“保存计划修改”，用于后续执行与报告
