# 报告组合（副驾驶流式）

- 逐章节生成：为每个章节设置备注与写作指南，支持流式预览与单章重生成
- 组合报告：按模板顺序合并已生成章节，支持在前端直接组装预览与保存为 `report.md`
- 进度与状态：显示后台组合进度、当前步骤与成功/失败标记

建议：
- 对关键章节（方法、结果、讨论）提供清晰的写作约束
- 生成完成后统一微调语气与术语一致性

操作要点：
- 章节管理：可选择章节、调整顺序，支持单章折叠/展开查看
- 图片路径：渲染时自动重写为 `/static/jobs/{job_id}/plots/` 前缀，保证跨页展示
- 前端组装：从静态目录读取已生成章节并组装，无需后端再次合并即可预览
- 流式生成：支持重试与中断；异常时优先检查后端日志与章节提示词
- 输出清理：章节末尾不会出现冗余JSON元信息（已修复），确保Markdown整洁
